## No warranty

This software is provided without any warranty, as described in sections 11 and 12 of the GNU General Public License, version 2. In particular:

- Writing a modified recovery requires an unlocked bootloader and root. It can leave the watch unable to boot, and a broken recovery partition also disables Wireless Download, which leaves opening the watch as the only way back.
- The recovery exposes an unauthenticated root shell on TCP port 5555. Anyone on the same network gets full control of the watch while it is in this recovery.
